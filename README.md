# 無盡冒險整合助手

[安裝／更新整合助手](https://raw.githubusercontent.com/Morpeko1021/Endless-Adventure-Assistant/main/%E7%84%A1%E7%9B%A1%E5%86%92%E9%9A%AA%E6%95%B4%E5%90%88%E5%8A%A9%E6%89%8B.user.js)

使用 Tampermonkey 安裝。此儲存庫提供正式單檔、內建自動更新入口、使用說明及歷史發布檔；沒有私人核心、擴充或登入憑證。

**目前版本 v0.95.4**，包含v0.95.3的離家與公會修正，並補修核心停止／未明操作核對。主面板寬470px、設定內容區300px，快速長條固定600px；設定使用統一的保存／關閉按鈕。指定隊伍固定CH.10曙光村集合，副本等待180秒、每場最多三次復活；方案中的種植可持續在後台等候成熟。自動戰鬥使用助手技能、公會技能選擇與F1～F4庫存監控。一般使用者預設獨立模式；私人授權核心模式也可從主面板派發單項任務或方案，固定互讚白名單保留。

本版修正原生離家明確未受理時的處理：集合先確認本人原生入口，可從已確認的訪客家園離開；false不留下假待核對，下一輪走原生地圖到曙光村，busy等待不連點。種植仍只操作自己的庭園，未知結果不重送，實際離家才完成。手動自動戰鬥支援八項已核對公會技能，新增兩項預設不選，原六項偏好與普通刷怪技能池保留。

核心停止補修採範圍受限的只讀核對：核對先前未明操作，禁止新發／重送原生操作或直接清除未知。僅核對本人原任務或與原啟動精確匹配的手動AUTO紀錄；重載保留原意圖，只有可靠原生證據才解除，人工停止後不自動接續。新路徑需助手v0.95.4及核心v0.21.3，既有v0.4.0擴充不用重載，一般操作權保持相容。

新來源有pending時長條與主面板持續顯示待核對，人工停止後不誤顯待命，AUTO仍阻擋。既有v0.95.2已有實帳470px主面板、300px內容及600px長條／收合定位不變證據；v0.95.4載入、拖動重載與實帳AUTO仍另核。

沿用刷怪／副本分項隊伍、身分鎖定、六來源快照與永久偏好隔離，以及種植後原線原房接續；保留核心補跑識別、背景常駐與正確方案名稱。已發布 v0.95.0、v0.95.1、v0.95.2 與歷史檔保留。

來源與測試單檔已凍結，1081／1081完整離線回歸通過，測試單檔1,300,057位元組；對應核心171項私人回歸通過。正式檔、專案檢查、服務部署、GitHub與公開更新核對見本版發布驗證；離線契約、真來源與真DOM測試不代替實帳操作，兩個獲授權角色的完整組隊／AUTO現場結果另記，不操作其他角色瀏覽器。v0.95.3只有本機正式建置，沒有Git／公開HTTP發布，其正式檔／說明保留。

舊 v0.93.0 沒有更新網址，須先由此入口更新一次，之後由 Tampermonkey 內建功能檢查新版。沿用已安裝腳本識別名稱與設定鍵。
