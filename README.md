# 無盡冒險整合助手

[安裝／更新整合助手](https://raw.githubusercontent.com/Morpeko1021/Endless-Adventure-Assistant/main/%E7%84%A1%E7%9B%A1%E5%86%92%E9%9A%AA%E6%95%B4%E5%90%88%E5%8A%A9%E6%89%8B.user.js)

使用 Tampermonkey 安裝。此儲存庫提供正式單檔、內建更新入口、說明及歷史發布檔；私人核心、擴充與登入憑證留在本機。

**目前版本 v0.96.0**，新增明確「接續」與「重新執行」入口，修正每日中途暫停後重跑仍停在舊來源、接續方案後排程未恢復，以及新任務誤用舊快照。主面板寬 470px、設定內容區 300px，九個功能按鈕排 5＋4；獨立拖動的快速長條目標 600px，遇視窗或 F1 邊界才安全縮短。

每日中途按「暫停」先等原操作到安全點；「接續」保留原執行與階段，方案繼續後續步驟。「重新執行」以目前選取設定建立新一輪；單項每日從第一階段重新檢查，交易及領獎證據保留，種植可能沿補跑規則產生新輪次。未明操作或原收尾未完成時不能重跑。方案重新從第一步開始，其中每日仍按原日誌略過已確認事項。

指定隊伍固定 CH.10 曙光村集合。分線改讀同本人、區域及世界的目前掛載原生 MiniMap，未知不猜；舊隊伍分線不能當作切線、到齊或返場證據。隊長及隊員等待每次 180 秒、連續三次失敗停止，每場最多三次原生復活。

長條 AUTO 在獨立及私人核心模式啟動目前地圖的助手技能攻擊，再按停止。支援八項已核對公會技能與 F1～F4 補品數量；使用設定副本，不更改永久偏好。核心 AUTO 暫停接續後沿同一人工任務停止，未明結果保留，不自行接續前一方案。

含種植的方案可持續在背景等候成熟；仍遵守原角色、頁面、操作權、收尾與未明核對限制。本版沿既有私人核心人工任務接口，不需要為本次接續修正重新配對。一般使用者預設獨立模式，沒有私人擴充時核心顯示不可用。

1,110／1,110 項完整離線回歸通過，正式單檔 1,306,716 位元組，與測試檔一致。離線真來源、單檔 DOM 與契約驗證不代替實帳流程；只有帕奇利茲、布撥獲授權現場驗收，其他掛網角色瀏覽器不操作。

固定互讚白名單沿用，使用者不能自行編輯。既有資料鍵及舊版本保留；使用 Tampermonkey 內建檢查更新。舊 v0.93.0 沒有更新網址，先由上方入口更新一次後即可使用內建更新功能。

詳見[使用說明](說明.md)。
