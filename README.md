# 無盡冒險整合助手

[安裝／更新整合助手](https://raw.githubusercontent.com/Morpeko1021/Endless-Adventure-Assistant/main/%E7%84%A1%E7%9B%A1%E5%86%92%E9%9A%AA%E6%95%B4%E5%90%88%E5%8A%A9%E6%89%8B.user.js)

**目前版本 v0.96.3**。修正每日及種植誤開家具「家園總覽」的問題，改用真正菜圃入口；收成、澆水沿原交易紀錄操作並核對成果。

例如每日完成後連刷副本，勾選副本插隊、取消刷怪插隊，副本到期可以各自種植並返回，練功期間禁止插隊。兩種模式的方案與單項入口一致，正在執行的快照不被後改設定覆蓋。

保留既有每日暫停、接續與重新執行，以及戰鬥、副本、野王、種植、組隊、AUTO、備份與角色設定。未明結果先核對，原交易與領獎證據不清除。指定隊伍仍固定CH.10曙光村集合。

農務入口與直接受影響功能 26 項取得通過。發布回歸誤選入口造成重複執行，已保存紀錄並停止；僅補驗未啟動及唯一失敗項，均通過。正式單檔 1,315,818 位元組，與凍結候選相同。方案三每日、五場副本及到期種植返回的完整實帳驗收尚未完成。

使用Tampermonkey正常更新入口；啟用檢查更新及自動安裝，可依標準週期自動取得新版，無法保證發布後立即安裝。已開遊戲頁於任務安全點重整後核對版本。此庫只提供正式單檔、metadata、說明及歷史版本；私人核心、擴充及憑證留本機，不需重新配對。
