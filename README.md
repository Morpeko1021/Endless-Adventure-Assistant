**目前版本 v0.97.2，發布日期 2026-10-16**。修復每日福利、補給的選取確認，以及副本隊員查園後沒有返回原村的卡點。每日、練等、副本及野王啟用種植插隊時，開始前先核對庭園，到期後等待安全交接、種植，再接續原任務。

好友互讚適用所有登入角色，對固定九人按讚並排除本人；先確認好友清單，只有清單確實缺少目標時才查人氣榜。

保留既有設定、未明操作紀錄、停止與接續，以及核心／獨立模式。未明操作仍須核對明確結果，更新不會清除紀錄或重新送出交易。

副本隊員查園後先返回原整備位置，再等待同隊進場；副本種植插隊等待結算返回後才交接，保留原場次。野王由原流程回王都、經阿丸重新尋王。每日採集返回原地圖、分線及座標後接續原進度，切線尚未確認時會等待。種植沿用固定正式來源 v2.2.1。

離線驗證與真實遊戲驗收分別記錄；尚未宣稱全部功能或完整方案已通過實帳。今日已完成的項目只讀核對，證據不足保留警示，不能以舊完成紀錄冒認本次成功。

使用 Tampermonkey 正常更新入口，更新後重新整理遊戲頁，並確認助手面板顯示 v0.97.2。核心模式須配合私人核心 v0.22.2；此庫僅提供正式單檔、metadata、說明與歷史版本。
