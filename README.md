# 無盡冒險整合助手

[安裝／更新整合助手](https://raw.githubusercontent.com/Morpeko1021/Endless-Adventure-Assistant/main/%E7%84%A1%E7%9B%A1%E5%86%92%E9%9A%AA%E6%95%B4%E5%90%88%E5%8A%A9%E6%89%8B.user.js)

使用 Tampermonkey 安裝。此儲存庫提供正式單檔、內建自動更新入口、使用說明及歷史發布檔；沒有私人核心、擴充或登入憑證。

目前版本 **v0.95.2**。正式單檔已生成並與通過測試的版本一致，發布與更新管道核對另記於本版發布驗證。主面板寬470px、設定內容區300px，快速長條固定600px；設定使用統一的保存／關閉按鈕。指定隊伍固定CH.10曙光村集合，副本等待180秒、每場最多三次復活；方案中的種植可持續在後台等候成熟。自動戰鬥使用助手技能、公會技能選擇與F1～F4庫存監控。一般使用者預設獨立模式；私人授權核心模式也可從主面板派發單項任務或方案，固定互讚白名單保留。

本版修正刷怪／副本逐步採用自己的隊伍，明確停用不繼承舊共用設定，角色選單與來源身分一致；六套來源執行快照不覆寫永久偏好。種植插隊後，隊長與野王以原生位置核對返回原地圖、分線與房間，再接續原執行；隊員跟隨隊長最新位置。保留核心補跑原執行識別、背景常駐與正確方案名稱。已發布 v0.95.0、v0.95.1 與歷史檔保留。

1042項離線回歸通過；介面預覽與真DOM測試屬模擬證據。兩個獲授權角色的最新版安裝與實帳組隊／AUTO仍待驗收，未操作其他角色瀏覽器。

舊 v0.93.0 沒有更新網址，須先由此入口更新一次，之後由 Tampermonkey 內建功能檢查新版。沿用已安裝腳本識別名稱與設定鍵。
