# 無盡冒險整合助手

[安裝／更新整合助手](https://raw.githubusercontent.com/Morpeko1021/Endless-Adventure-Assistant/main/%E7%84%A1%E7%9B%A1%E5%86%92%E9%9A%AA%E6%95%B4%E5%90%88%E5%8A%A9%E6%89%8B.user.js)

使用 Tampermonkey 安裝。此儲存庫提供正式單檔、內建自動更新入口、使用說明及歷史發布檔；沒有私人核心、擴充或登入憑證。

目前版本 **v0.95.1**。主面板寬470px、設定內容區300px，快速長條固定600px；設定使用統一的保存／關閉按鈕。指定隊伍固定CH.10曙光村集合，副本等待180秒、每場最多三次復活；方案中的種植可持續在後台等候成熟。自動戰鬥使用助手技能、公會技能選擇與F1～F4庫存監控。一般使用者預設獨立模式；私人授權核心模式也可從主面板派發單項任務或方案，固定互讚白名單保留。

本修訂版修正核心補跑的原執行核對：方案核對 planId，單項核對 taskKind 且須屬單項執行，兩者皆確認 runId 與原快照一致才接續；不符或選取其他方案時走安全啟動，不借用另一個執行的快照。核心背景種植待命仍保持快速長條展開，任務占用時自動戰鬥不可用，長條正確顯示方案1／2／3。已發布 v0.95.0 與歷史檔保留。

舊 v0.93.0 沒有更新網址，須先由此入口更新一次，之後由 Tampermonkey 內建功能檢查新版。沿用已安裝腳本識別名稱與設定鍵。
