# 無盡冒險整合助手

[安裝／更新整合助手](https://raw.githubusercontent.com/Morpeko1021/Endless-Adventure-Assistant/main/%E7%84%A1%E7%9B%A1%E5%86%92%E9%9A%AA%E6%95%B4%E5%90%88%E5%8A%A9%E6%89%8B.user.js)

**v0.97.3，版本日期 2026-10-16**。修正每日交易在核心派出安全暫停後、助手接收前開始時，暫停遭拒而遺失接續快照的交接問題。助手先等待該筆原交易自然確認，再保存同一執行的安全快照；不重送交易。

每日、練等、副本及野王啟用種植插隊時，開始前先核對庭園，到期後等待安全交接、種植，再接續原任務。

好友互讚適用所有登入角色，對固定九人按讚並排除本人；先確認好友清單，只有清單確實缺少目標時才查人氣榜。

保留既有設定、未明操作紀錄、停止與接續，以及核心／獨立模式。未明操作仍須核對明確結果，更新不會清除紀錄或重新送出交易。

副本隊員查園後先返回原整備位置，再等待同隊進場；副本種植插隊等待結算返回後才交接，保留原場次。野王由原流程回王都、經阿丸重新尋王。每日採集返回原地圖、分線及座標後接續原進度，切線尚未確認時會等待。種植沿用固定正式來源 v2.2.1。

正式單檔、公開最新檔及本版歷史檔已保存，與凍結候選完整一致。本版定向驗證 10 項通過，另有 1 項真核心跨層案例通過，確認等待交易期間續租及同一執行接續；發布前唯一完整回歸 1435/1435 通過。兩個已有通過證據的凍結案例未重跑，原始失敗紀錄保留。這些離線證據不代替實帳：咚咚鼠的每日→副本方案、到期種植插隊及原進度接續仍未完整驗收。今日已完成的項目只讀核對，證據不足保留警示，不能以舊完成紀錄冒認本次成功。

使用 Tampermonkey 正常更新入口，更新後重新整理遊戲頁，並確認助手面板顯示 v0.97.3。核心模式須配合私人核心 v0.22.2；本版沒有更動私人核心。此庫僅提供正式單檔、metadata、說明與歷史版本。
